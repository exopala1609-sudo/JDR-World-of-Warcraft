=============================================================================
  LE RÉFÉRENTIEL : les règles de création de personnage
=============================================================================

Ce dossier contient les règles que l'écran « Créer un personnage » utilise :

  factions.json     Alliance, Horde...
  races.json        Les peuples : faction, traits, choix (lignée, taille...)
  classes.json      Les classes : dé de vie, spécialisations, lore, ressources
  historiques.json  Les historiques : bonus de caractéristiques, don d'origine
  dons.json         Les dons (d'origine, généraux...)
  langues.json      Les langues : table de faction, langues rares
  renommees.json    Les factions de renommée (Forgefer, Kirin Tor...)
  ressources.json   Les jauges et compteurs : Mana, Rage, Énergie...
  creation.json     Tableau standard et achat de points

Le jeu ne connaît AUCUNE race ni AUCUNE classe par son nom : tout vient de
ces fichiers. Tu peux donc les modifier sans toucher au code du jeu.


--- Ouvrir et modifier un fichier -------------------------------------------

  1. Clic droit sur le fichier > Ouvrir avec > Bloc-notes.
  2. Modifie, puis enregistre (Ctrl + S).
  3. Vérifie ton travail : dans l'Invite de commandes, depuis le dossier du
     projet, tape :   npm run verifier-referentiel
     Le serveur n'a pas besoin d'être lancé.
  4. Si la partie est en cours : outils du MJ > « Recharger le référentiel ».
     Inutile de redémarrer le serveur.

Chaque fichier explique ses champs dans les lignes qui commencent par //.
Ce sont des commentaires : le jeu les ignore.


--- Les 4 règles d'or -------------------------------------------------------

  1. Ne change JAMAIS un "id" une fois des personnages créés : les fiches
     l'enregistrent. Pour renommer, change seulement "nom".
  2. Les textes s'écrivent entre guillemets droits "comme ceci", jamais
     entre guillemets courbes “comme ceci”.
  3. Une virgule sépare deux éléments d'une liste.
  4. Avant toute grosse modification, copie le fichier (ex. races-avant.txt).
     Attention : une copie en .json serait lue elle aussi, en double.

Si tu fais une erreur, le jeu t'indique le fichier, la ligne et la raison.
L'entrée fautive est ignorée, le reste continue de fonctionner.


--- Le livre officiel et ces exemples ----------------------------------------

Ces exemples ne contiennent que du contenu LIBRE : 5 espèces, 4 historiques
et quelques dons du SRD 5.2 de Wizards of the Coast, plus les 13 classes WoW
décrites avec leurs règles de base. Les traits du livre « D&D World of
Warcraft » n'y figurent pas : ils sont protégés et le projet est public.

Les fichiers tirés du livre se mettent ICI, dans ce dossier (NAS ou cloud),
jamais dans le dossier du projet. Ils remplacent les exemples.

Ce dossier n'est rempli automatiquement qu'une seule fois (quand il est vide).
Le jeu n'écrase donc jamais tes modifications.
